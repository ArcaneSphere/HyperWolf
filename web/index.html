🚀 Getting Started

HyperWolf is a standalone desktop application for browsing TELA decentralized applications on the DERO blockchain.

First launch: you'll be asked to choose a node — pick one of the suggested nodes or enter your own. Your choice becomes your default node, which HyperWolf auto-connects to on every start (changeable anytime in Settings → Connection).

  1. Choose a node on first launch (or skip and set one later)
  2. Wait for Gnomon sync — the Search page fills in as apps are discovered
  3. Search for TELA apps or paste a SCID directly
  4. Click an app to open it in your browser

The app opens on the Search page. Node and daemon details live on the Node Status page.

🔍 Search

Search is the home page. It indexes TELA apps via HyperGnomon and lets you find SCIDs by name, URL, SCID or description.

  • Search box — fuzzy-matches app name, URL (dURL), SCID and description; suggestions appear as you type.
  • Min rating — slider to filter apps by community rating.
  • Sort — Top Rated, Name A→Z / Z→A, Newest / Oldest SCID.
  • All SCIDs — toggle to list every discovered SCID.
  • Hidden extensions — exclude file types (e.g. .jpg, .js, .shards) in Settings → Search.
  • Direct Load — when enabled, clicking a result loads the SCID in a new tab automatically.

Cards (bottom of the page; hideable in Settings):

  • Latest Finds — newest discovered apps, with ✨ markers for apps found since your last visit.
  • Updates & News — HyperWolf update banner plus the Dero.World AnotherWorld RSS feed.
  • Node Status — at-a-glance server status.

⭐ Bookmarks

Save nodes and SCIDs for quick access — click the ☆ buttons next to the node/SCID inputs or on search results, then give them a label. The suggested nodes from first launch are pre-bookmarked. Manage, rename or remove them on the Bookmarks page.

🔗 Connect

  • Use your own local node for best performance and reliability.
  • Public nodes also work well — find them on the Bookmarks page.
  • Set your preferred node and enable Auto-Connect in Settings → Connection.
  • First Gnomon sync ~17 seconds, SCID loading 3–15 seconds depending on app size.

⚙️ Settings

  • Connection — default node, auto-connect, open dashboard on startup, show top bar.
  • Search — direct-load SCIDs, show/hide the cards panel, hidden extensions.
  • Live Info Card — update checks and the RSS feed shown in the Updates & News card.
  • Themes — dark/light mode and the Search page gradient background.
  • Data — reset all settings to their defaults.

📋 Activity Log

HyperWolf logs what it's doing — connections, sync, discovery and errors. On the Activity Log page you can:

  • Filter by level (Info / Warning / Error / Success).
  • Auto-follow the latest entries as they stream in.
  • Clear the log, or refresh it manually.

🔐 Web Socket (xswd)

You can browse TELA apps freely but XSWD (Dero WebSocket Daemon) is required by some TELA apps (like for example vault.tela) for wallet operations, to get the full TELA experience:

  1. Download the latest Engram release from github.com/moralpriest/Engram/releases
  2. Start your wallet, go to setting and turn on Web Sockets (WS)
  3. HyperWolf listens on ws://127.0.0.1:44326

HyperWolf detects xswd automatically and shows its status in the sidebar.

ℹ️ About HyperWolf

Version: 0.8.5

Description: Standalone desktop application to access TELA's decentralized applications and websites from the DERO blockchain.

🛠 Built With

HyperWolf is powered by:

  • Civilware Tela — TELA server for serving decentralized applications
  • HyperGnomon — blockchain indexer for SCID discovery and search
